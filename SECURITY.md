# Security policy

HoneyView is defensive software designed to receive hostile input. Report vulnerabilities privately to the project owner and include the affected version, reproduction steps, impact, and suggested remediation.

Do not include real credentials, sensitive captured data, or public honeypot addresses in a report. Do not test a deployment you do not own or have explicit authorization to assess.

The following are deliberate behavior, not vulnerabilities:

- accepting arbitrary non-empty decoy passwords;
- returning simulated host data;
- recording commands and behavioral timing;
- preventing outbound downloads and command execution.
